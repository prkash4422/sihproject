# ProcurePilot Assumptions & Governance Guardrails

1. **Official Portals Remain Source of Truth**: ProcurePilot is an intelligent assistant layer. It does not replace official submission portals (GeM, CPPP).
2. **Deterministic Rules Overrule AI**: AI models assist with text extraction and semantic question answering, but NEVER make binding eligibility or qualification decisions.
3. **Ambiguity Yields Review**: Any unclear requirement or conflicting tender statement is surfaced as `NEEDS_REVIEW` with an advisory to seek official pre-bid clarification.
4. **Seed Dataset Authenticity**: Demonstrations use curated, realistic tender specifications modeled after real Indian public procurement tenders.
