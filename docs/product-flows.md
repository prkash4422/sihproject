# ProcurePilot Product Flows & User Journeys

## 1. Primary Startup Journey
```
[ 1. Multi-Step Onboarding (12 Steps) ]
  - Basics, DPIIT & Udyam recognition, capabilities, financials, certs, documents
                    │
                    ▼
[ 2. Capability Fingerprint Generation ]
  - Vector & categorical representation of startup strengths
                    │
                    ▼
[ 3. Tender Discovery Feed ]
  - Search by keyword, department, category, value, deadline
  - Real-time Match Score badges & Eligibility preview
                    │
                    ▼
[ 4. Tender Deep Dive & "Analyse Tender" ]
  - Asynchronous requirement extraction pipeline
  - Page-by-page requirement breakdown
                    │
                    ▼
[ 5. Deterministic Eligibility & Match Rationale ]
  - PASS / FAIL / NEEDS_REVIEW breakdown with GFR 161(iv) citations
  - Weighted Match score explanation
                    │
                    ▼
[ 6. Gap Analysis & Dynamic Compliance Checklist ]
  - Actionable checklist with missing document indicators
  - Upload & map evidence directly
                    │
                    ▼
[ 7. Grounded Tender Q&A ]
  - Ask specific queries -> receive grounded answers citing exact pages
                    │
                    ▼
[ 8. Opportunity Tracker (Kanban) ]
  - Move from INTERESTED -> PREPARING -> SUBMITTED with readiness score
```

## 2. Admin Governance Journey
```
[ Admin Dashboard ]
  ├── Review Queue: Inspect low-confidence or ambiguous extracted requirements
  ├── Policy Rule Manager: View and update GFR & DPIIT relaxation rules
  └── Audit Log: Search immutable system activities and evaluations
```
